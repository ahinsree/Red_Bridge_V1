# CLAUDE.md — Red Bridge Advisory website

Read `README.md` and `PRODUCT.md` before starting any task.

## Ground rules

- **Work in phases.** Complete one phase, then stop with a summary (what changed + why, manual steps, risks/open questions) and wait for approval before continuing.
- **One branch per phase** (e.g. `phase-0-foundations`, `phase-1-deploy-perf`). Commit in small, logical steps with clear messages.
- **Before every commit** run `npx tsc --noEmit` and `npm run lint`. Both must pass.
- **Copy is not yours to change.** Do not change website copy, positioning or Insights article content unless the phase explicitly says so. Flag content issues instead.
- **No deletions without confirmation.** List files to be deleted and get approval first.
- **Keep the brand**: glassmorphism, crimson accent `#B22030`, premium micro-animations (see Brand below).
- **Never commit secrets.** Use environment variables and keep `.env.example` up to date.

## Stack

- Next.js 15 (App Router) · React 19 · TypeScript 5
- Tailwind CSS v4 (`@import "tailwindcss"` + `@theme` in `src/app/globals.css`) alongside a large hand-written BEM-style stylesheet in the same file
- Framer Motion 12 (drawers, chatbot, hover springs). `gsap` and `three` are also in `package.json`; standardizing on Framer Motion is planned
- lucide-react icons
- Decap CMS at `/admin` (`public/admin/config.yml`), GitHub backend, OAuth via `/api/auth` + `/api/callback`
- Hosting: target is **Vercel** (API routes, redirects and headers need a server). GitHub Pages workflows in `.github/workflows/` are legacy

## Commands

```bash
npm run dev          # runs compile-insights.js first (predev)
npm run build        # runs compile-insights.js first (prebuild)
npx tsc --noEmit     # type check — must pass before commit
npm run lint         # eslint — must pass before commit
npx decap-server     # local CMS backend for /admin
node watch-insights.js  # recompile insights on CMS save (local)
```

## Folder conventions

```
src/app/                 routes (App Router)
  api/contact/           POST → Google Sheets proxy (GOOGLE_SCRIPT_URL)
  api/auth, api/callback Decap CMS GitHub OAuth (GITHUB_CLIENT_ID / _SECRET)
  practices/[slug]/      practice-area detail pages
  <member-slug>/         digital visiting cards (being consolidated into team/[slug])
  sitemap.ts, layout.tsx, globals.css
src/components/          page sections + floating UI (flat for now; planned split:
                         sections/, ui/, features/)
src/data/
  insights/*.md          CMS-authored articles (source of truth)
  insights.json          GENERATED by compile-insights.js — do not hand-edit
public/
  images/                site imagery; images/uploads/ is the CMS media folder
  admin/                 Decap CMS entry + config
  *.vcf                  vCards for visiting cards
```

Conventions going forward:
- Content (nav links, practices, sectors, chatbot rules, team members) belongs in `src/data/*.ts`, not inline in components.
- Prefer Server Components; add `"use client"` only to the interactive leaf that needs it.
- Use `next/image` for raster images; keep assets in `public/images/` as WebP/AVIF.
- Any animation must respect `prefers-reduced-motion`.
- Do not hand-edit generated files (`src/data/insights.json`).

## Brand tokens

Defined in `src/app/globals.css` (`@theme` for Tailwind, `:root` for the CSS layer).

| Token | Value | Use |
|---|---|---|
| `--red` / `bridge-red` | `#B22030` | Primary accent, CTAs, labels |
| `--red-dark` | `#8B0000` | CTA hover |
| logo red | `#C2192A` | Logo mark only (Header/Footer) — reconcile with `--red` |
| `--navy` / `deep-navy` | `#1B263B` | Hero, footer, dark bands |
| `--charcoal` | `#1C1C1C` | Headings on light, dark sections |
| `--body-c` | `#2E2E2E` | Body text |
| `--muted` | `#6B6B6B` | Secondary text (check contrast on cream) |
| `--cream` / `cream` | `#EDEAE2` | Light sections; text on dark |
| `--offwhite` | `#FAFAF8` | Page background |
| `--divider` | `#C8C4BC` | Rules, borders |
| dark glass | `#0c101b` @ 70% + `blur(24px)` + `border-white/10` | Chatbot, Insight drawer |

- **Fonts:** Cormorant Garamond (`--font-serif`, headings, often italic) and DM Sans (`--font-sans`, body) via `next/font/google` in `layout.tsx`.
- **Layout:** `--max: 1240px`; side padding `--pad` 80px → 32px (≤960) → 20px (≤520).
- **Motion:** `--ease` 0.22s, `--ease-hover` 0.32s `cubic-bezier(0.25,0.46,0.45,0.94)`, `.reveal` scroll-in (0.78s).
- **Theme reality check:** the site is currently a light editorial base (off-white/cream) with dark navy/charcoal bands and dark glass overlays. It is not an all-dark theme. Confirm with the owner before changing that direction.
